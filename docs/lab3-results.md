# ЛР3 Безопасный CI/CD для SMS-классификатора

Реализованы GitHub Actions, дополнительные поведенческие тесты, Ruff, Bandit, pip-audit, data gate, model gate, сборка Docker, проверка конфигурации и сканирование реального образа Trivy. Команды и политики приведены в корневом README. Результаты фактических запусков и ссылки добавляются после завершения проверки.

## Происхождение контрольной выборки

Источник — официальный UCI SMS Spam Collection. SHA256 исходного файла: `7d039a24a6083ed9ef0f806ebad56bbb976e3aeb8de05669173bfdc4996c239d`. После нормализации дублей выполняется разделение ЛР2 с seed=42. Контрольная двадцатка содержит фиксированные ID из test и не пересекается с train. Её SHA256: `9beff59f298fc29a534734045629335d66f7b7ad5d0d4feba41acb51707023f3`.

Схема JSON: `version`, `source_sha256`, `records`; каждая запись содержит целочисленный `row_id`, `label` из `ham/spam` и непустую UTF-8 строку `message` длиной до 1000 символов без NUL. Пропуски/NaN/Inf отклоняются. Ожидается ровно 20 уникальных записей, доля spam в [0,45; 0,55], точное совпадение ID, версии и SHA256. Эти правила хранятся отдельно в `config/data_policy.json`.

## Сравнение модели

Эталон — сохранённый Pipeline ЛР2, SHA256 `f054edc2c35248ad9cb26a78ce7d8be044558fe39d3d73d8cf487777bbfeb06a`. На контроле baseline F1 spam равен 0,9473684211, порог — 0,9000. Это оценка той же модели на фиксированной подвыборке, а не замена результата ЛР2 на полном test. В каждом CI оценивается сохранённый кандидатный артефакт; baseline автоматически не перезаписывается. На сервере используется проверенная копия модели ЛР2, а на чистом runner кандидат обучается из проверенных данных с теми же параметрами и seed. Его SHA256 может отличаться на другой машине; собственный манифест кандидата проверяется при загрузке и сборке контейнера. Исходная модель и эталоны ЛР2 сохраняются отдельно и не изменяются.

## Демонстрации отказа

| Сценарий | Нарушение | Ожидаемый отказ | Последующие этапы |
|---|---|---|---|
| `data` | Неверная метка в копии CI-данных | Data quality gate, exit 1 | Оценка, model gate, сборка и проверки контейнера не запускаются |
| `model` | Настоящий константный кандидат выдаёт ham, F1 spam = 0 | Model quality gate, exit 1 | Сборка и проверки контейнера не запускаются |
| `security` | Имитированный отчёт `SIMULATED-CRITICAL-0001` | Security policy demonstration, exit 1 | Data/model gate и сборка не запускаются |

Security-демонстрация безопасна: уязвимый пакет не установлен, уязвимый сервис не запускается, секреты не создаются. Она проверяет логику обработки отчёта; фактическое сканирование зависимостей, Dockerfile и собранного образа подтверждается отдельными реальными отчётами успешного запуска.
