# ЛР1: требования и подтверждённые сведения

В предоставленной сохранённой странице LMS ЛР1 отмечена принятой на 20/20. Ранее сданный PDF не входил в эти изменения. Принятие преподавателем не заменяет текущую проверку состояния сервера.

Направление — NLP, классификация SMS для сервиса фильтрации: строка на входе, ham/spam на выходе. Проект работает от отдельного `mluser`, не root; используется проектное `.venv`, Python 3.14.4, структура data/notebooks/src/models/tests. Данные — SMS Spam Collection UCI, два класса; размеры и дисбаланс приведены в README и ноутбуке. Эталон SHA256 исходного файла совпадает с сохранённым на сервере эталоном ЛР1.

Версии ML-зависимостей закреплены в requirements.txt; pip check подтверждает согласованность пакетов, но не отсутствие уязвимостей. Старый audit-report.json не охватывает pandas, numpy и scikit-learn и не является подтверждением аудита всего ML-окружения. Свежий онлайн pip-audit, SSH-доступ по ключу, запрет root, UFW, Docker/Compose, IDE и история apt-обновлений в рамках исправления ЛР2 не перенастраивались и заново не подтверждались. Текущий служебный доступ выполнялся по паролю через корпоративный VPN.

## Мини-модель угроз

| Актив | Угроза | Последствие | Контрмера и её статус |
|---|---|---|---|
| SSH | Подбор пароля | Доступ к серверу | Отдельный пользователь и VPN используются. SSH-ключи, PermitRootLogin no и UFW limit предписаны ЛР1; актуальная конфигурация в этом изменении не проверена. |
| Датасет | Подмена файла | Обучение на изменённых данных | Реализованы сравнение SHA256 с отдельным эталоном и прекращение обучения при несовпадении. Хэш сам по себе не подтверждает происхождение. |
| Модель | Подмена joblib / загрузка чужого pickle | Выполнение кода и неверные ответы | Используется собственный локальный артефакт, SHA256 проверяется до загрузки. Ограничение прав на хранилище — дополнительная мера для отдельной проверки. |
| Git | Публикация секретов и сырых данных | Утечка содержимого и доступа | .env/ключи/данные/модели исключены из текущего индекса; выводы ноутбуков не содержат SMS. Проверка всей истории и её очистка при необходимости — отдельная мера, сейчас не выполнена. |
| ML-вход | Опечатки, нетипичный текст или чрезмерный размер | Ошибочный ответ либо лишние затраты ресурсов | Валидация и предел длины реализованы; проведён эксперимент. Защита до HTTP-декодирования и отказ для входов без словарных признаков предложены для будущего API, не реализованы. |
